Autenticación

La API exige JWT en todos los endpoints. Usa una de las credenciales sembradas.

Agente conversacional LangGraph

Cada mensaje recorre el grafo: classify_intent → get_customer_info → handler → check_escalation → generate_response. La intención sale del clasificador de tickets y la frustración del modelo de sentimiento.

Escribe un mensaje para iniciar la conversación

Clasificación de tickets scikit-learn

TF-IDF + Logistic Regression. Devuelve la categoría y la probabilidad de cada clase.

Análisis de sentimiento Keras · LSTM

Embedding → LSTM → Dense. is_frustrated es la señal que usa el agente para escalar.

Predicción de churn scikit-learn

Gradient Boosting sobre features del cliente + 2 features derivados.

Tiempo de resolución Keras · multi-input

Regresión con inputs mixtos: texto (embeddings) + categoría/prioridad (one-hot) + hora y día (cíclicos).
